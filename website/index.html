Your own private network, on a server you own.

Covee connects your people and devices over direct, encrypted connections, wherever they are.

One command builds the network on your server, sign-in and certificate included.

You need a fresh Ubuntu 24.04 server reachable on TCP 443 and UDP 3478, a domain name, and a way for people to sign in.

Three parts, all of them yours.

The covee command builds and runs the network from your computer. The server coordinates and relays. Your devices talk to each other directly, end to end encrypted; the server cannot read that traffic.

Signs in with your network identity: no key or password.

  • A terminal with no keys to copy. Servers running Tailscale SSH let you in with your network identity. Elsewhere Covee signs in with its own key, kept in your device’s Secure Enclave.
  • Screen sharing. On iPhone and iPad the screen opens right in Covee, with touch, zoom and a keyboard with modifier keys; on a Mac, in Apple’s Screen Sharing.
  • Every device checked. Covee confirms a device’s identity the first time and refuses to connect if it ever changes.

4. Reach what only your server can.

  • Address ranges or host names. Names are looked up from the server, so a private endpoint gets its private address.
  • Private DNS. Names like vault.azure.net resolve through your cloud’s resolver.
  • Access kept in step. The console writes the matching access rules, and never touches rules it did not add.

Everything a network needs, set up for you.

covee setup does the hard parts of running your own coordinator, and checks everything before it changes anything.

Sign-in people already have
Microsoft Entra ID, Google and Apple, or Covee’s own accounts with a passkey or a password and authenticator. Each network registers its own Microsoft app and group.
A hardened server
A firewall that admits only what the network needs, SSH limited to one key-only account, and services running unprivileged with read-only file systems.
DNS and certificates
Records kept in Route 53 or Cloudflare, a home address followed as it changes (with Route 53), and a Let’s Encrypt certificate proved through DNS, so no port needs to be open first.
A private admin console
People, devices, keys, access rules and the gateway, with every change recorded. Reached through an SSH tunnel, or from inside the network, never from the internet.
Backups you can restore
Encrypted snapshots, checked on your computer, that rebuild the network on a new server with every device, account and setting.
Exit nodes and shared networks
A device can send others’ internet traffic out through itself, or share the network behind it, once an administrator approves it.
Stays connected
Covee for Mac and iPhone reconnect by themselves after sleep, a network change or a server restart, and keep a short history of why a connection ended.
Your networks, one tap apart
Home, work, a client’s network: the apps remember each one and its sign-in, so moving between them takes one tap instead of an address.

Open source, end to end.

Covee is free under the Apache 2.0 license. It builds on Headscale, an open-source implementation of the Tailscale control server, and on Tailscale’s open-source client engine. Nothing reports home: the command and the apps talk only to your server and the providers you choose.
